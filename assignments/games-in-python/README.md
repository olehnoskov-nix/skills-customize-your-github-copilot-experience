
# 📘 Assignment: Games in Python

## 🎯 Objective

Create a fun Python game that uses loops, conditionals, random values, and user input to provide an engaging interactive experience.

## 📝 Tasks

### 🛠️ Create a Simple Game

#### Description
Build a small game in Python, such as Hangman, a guessing game, or another beginner-friendly game that uses user input and repeated logic.

#### Requirements
Completed program should:

- Use Python input and output to interact with the player
- Include a loop that continues until the player wins or loses
- Use conditionals to check guesses, scores, or game state
- Use at least one random element or repeated decision point
- Display clear win/lose messages at the end of the game

### 🛠️ Add Game Logic

#### Description
Improve your game by adding score tracking, attempts, or progress updates so the player can clearly understand the current state of the game.

#### Requirements
Completed program should:

- Track the player's remaining attempts or score
- Show the current state of the game after each turn
- Validate user input so invalid choices are handled gracefully
- End the game when the player wins or runs out of attempts
- Include a short explanation of the rules before the game starts
